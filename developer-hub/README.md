# Vava Living Developer Hub

Central development workspace for Vava Living.

This module tracks product development, bugs, UI/UX improvements, patches, releases, deployments, and technical decisions for the Vava Living website.

## Core repositories
- Main application: `mohamedamouseo-a11y/Vava-living-website`
- Patch repository: `mohamedamouseo-a11y/Vava-living-website-patches`

## Workflow
`Backlog -> Ready -> In Progress -> Review -> Testing -> Done`

## Work item types
- Feature
- Bug
- UI/UX
- Performance
- SEO
- Content / CMS
- Infrastructure / Deployment
- Security
- Technical debt

## Required task information
Each development task should include:
- Title
- Type
- Priority
- Status
- Scope / affected area
- Problem or requested outcome
- Acceptance criteria
- Related branch / commit / PR / patch
- Testing notes
- Deployment status

## Priority levels
- P0 — Critical / production blocker
- P1 — High
- P2 — Medium
- P3 — Low

## Hub sections
- `backlog.md` — planned and requested work
- `active-work.md` — currently active work
- `release-log.md` — shipped changes and deployments
- `technical-decisions.md` — important architecture/product engineering decisions

## Operating rule
No development task is considered complete until implementation, review/testing, and deployment state are recorded.
